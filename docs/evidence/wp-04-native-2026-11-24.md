## Actual-release API research

Two separate read-only agents inspected the installed release sources/types.
Their reports were reviewed as research, not executable proof. Native sources are
TanStack React Table/core **9.3.1**; collection sources are HeroUI **3.2.8**, React
Aria **3.53.1**, Aria Components **1.22.1** and Stately **3.51.0**. Research began
2026-11-23; no runtime check is inferred from source reading.

- V9 exposes `useTable`, `tableFeatures` and feature-registered filtered/sorted/
  paginated model factories. Feature generics precede record generics. No v8
  `useReactTable` or whole-state change callback is needed.
- Global filtering only considers eligible accessor leaves, even when hidden.
  Exactly one internal accessor carrier can evaluate the composite WP-02 filter.
  `createFilteredRowModel` memoizes on input rows, columnFilters and globalFilter;
  replacing only a function closure is insufficient. A changed evaluator capsule
  must participate in accepted controlled globalFilter state.
- Native per-slice callbacks accept direct/functional updaters. Their owners must
  resolve against current accepted controller state, not a captured React render.
  Disable native automatic resets; controller transitions own atomic resets and
  controlled proposals. Native whole reset/base-atom writes are not safe facades.
- Manual filtering/sorting/pagination bypass those model stages for supplied
  server pages. Unknown `pageCount: -1` makes native next-page capability always
  true; the application hasNextPage flag must control supported navigation.
- React Table's state subscriptions do not include data/options. Memoized leaves
  also need changed row/model/metadata props for same-query data-only refreshes.
- HeroUI's `Table.Content`, not its outer wrapper, receives controlled selection
  and sorting. Its stock `Table.Column` wraps Aria's **leaf** collection component;
  it does not expose Stately's distinct nested-column construction contract.
  Internal grouped header machinery alone does not prove public composition.
- A public `react-aria/CollectionBuilder` branch adapter is a candidate, not yet
  proven. Uneven depths introduce placeholder-header rendering risk. The bounded
  collection spike must prove actual structure/semantics before G-01 acceptance.
- Aria native select-all emits dataset-wide `"all"`; its default header checkbox
  cannot implement Tableweave's page-only union/subtraction with off-page IDs.
  A controlled page checkbox and explicit native event policy are required.
- Aria has one sort descriptor. Multiple accepted sort keys require explicit
  priority actions/descriptions, with directional aria-sort on the primary only.

Source anchors are installed `dist/useTable.*`, core feature/model implementations,
HeroUI `dist/components/table/table.*`, Aria Components `Table.d.ts` and its shipped
Table source map, plus Aria `CollectionBuilder` and Stately selection sources.
These vendor files are not copied into the repository or modified.
