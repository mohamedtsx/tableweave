# Design and component review

The existing transactions Figma is exploratory. HLD §§16–20 define a **future**
complete designer handoff; no new Figma design was created in this documentation
task. Visual work must stay consistent with product requirements and technical
interaction contracts, and requires its own authorized task.

- [Designer handoff](handoff.md): authority, references, tokens/anatomy,
  configurations, component inventory, F-01–F-22, responsive/RTL and copy.
- [Storybook](storybook.md): corresponding component/state/interaction workbench.
- [Rendering](../engineering/rendering.md): native collection, selection and
  arbitrary details slots.
- [Quality](../../product/quality.md): accessibility/localization/responsive targets.

A beautiful frame is not acceptance if it changes field ownership, clears hidden
criteria, invents built-in Export, hides data automatically, or omits recovery.
Figma feature booleans describe developer configuration, not an end-user settings
panel. Future approved visuals can own appearance consistent with PRD/HLD, never
silently supersede behavior. No commercial reference source/assets are licensed
for redistribution by these links.
