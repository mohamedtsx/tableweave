# Product specifications

The [Notion PRD](https://app.notion.com/p/mohamedtsx/Tableweave-PRD-42061b5e62648054aa06dcb0ed4ba0c8)
v1.0 is the product baseline. These are its focused local owners, not evidence of
implementation. Changes identify affected FR/D IDs and receive product review.

| Concern | Canonical owner |
| --- | --- |
| Promise, users, jobs, goals, exclusions, evidence, risks | [Overview](overview.md) |
| Confirmed product decisions D-01–D-40 | [Decision register](decisions.md) |
| Functional requirements and acceptance FR-01–FR-16 | [Features](features.md) |
| Type/operator vocabulary, drafts, null/empty and date semantics | [Operators](operators.md) |
| Filtering, selection, ordering, controls and ownership invariants | [Shared rules](shared-rules.md) |
| Initial/refresh/error/empty and tool recovery | [Recovery](recovery.md) |
| Accessibility, compatibility, localization, performance and privacy | [Quality](quality.md) |
| Developer experience, validation measures and stable-release gates | [Release gates](release-gates.md) |
| Integrated, derived acceptance scenarios | [Acceptance](acceptance.md) |
| Product → contract → scenario → packet lookup | [Traceability](traceability.md) |
| Source contradictions versus engineering/publication inputs | [Open items](open-questions.md) |

The [source manifest](../docs/reference/source-manifest.md) maps all PRD/HLD
sections and acquisition metadata. The [HLD-derived engineering map](../docs/engineering/README.md)
and [design handoff](../docs/design/handoff.md) translate the approved product
contract without freezing untested APIs. Do not load this entire map by default.
