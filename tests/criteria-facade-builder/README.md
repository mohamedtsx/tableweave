## Actual host acceptance contract

The store still has its original `commit(input: unknown): void` API, own keys,
mount lifetime and actual Builder F3 cell. No extra cell, participant, source
engine, app permission predicate, latest-config ref or public wrapper was added.
The only new persistent pin is an opaque facade identity, not private payload.

1. Use the frozen toolbar's `captureCriteriaCandidate`. True omission keeps the raw
   route; registered unready input pins adopted mode and never downgrades to legacy.
   Invalid/present metadata never selects the raw branch for that configuration.
2. Prove the genuine tool/owner, actual C/CD/P, exact mount/operation and old owner
   pin before private fields. For registered facade input, read **own metadata
   only**: controller, registered criteria identity, library invalidation key `0`,
   `expectedResourceContext` definition/scope/access and client/server mode.
3. Use actual `criteriaFacadeState`, `criteriaFacadeIdentity` and
   `criteriaFacadeSameSource`. Waiting/superseded/unchanged-ticket coalescing requires
   the same real source as the committed pin, current actual actor/lease/adopted
   mode, `requireActor(actor)`'s exact F3 presentation association, matching real
   C/CD/P/origin/epoch/access and the old committed evaluation mode. An unknown
   source marker, null prior pin or core actor alone is not owned presentation.
4. A valid coalescing return changes neither actor, presentation, local state,
   registrations, work, subscriptions nor either snapshot/version; it does not call
   child commit, reconcile Date/Builder, acquire/release F2 claims, or notify.
5. Around a real child commit, make exactly one actual
   `prepareCriteriaFacadeHost(input)` carrier. On successful child L-config only,
   `takeCriteriaFacadePresentation(carrier, input)` supplies `className`. Publish
   the existing F3 presentation first, then retain successful target/source metadata
   and run original Builder/Date reconciliation and controller subscription logic.
   The host never reads/spreads/traverses private facade config for presentation.
6. On error, only the actual closed
   `consumeCriteriaFacadeHostSkip(error, input, cell, carrier)` with unchanged host
   mount/operation suppresses retire/publication/reconcile/notification. A SKIP is
   **not** a successful B commit and does not retag A's target or source pin.
   `closeCriteriaFacadeHost(carrier)` runs in `finally` on every path, including
   success, skip and denial; no private carrier payload is backed up.

The frozen S3 adapter/F3a separately validates fixed builder kind, actual source
mode, native registry/defaults and all current config metadata/private fields at
real L-config. Client maps to client; server/server-complete map to server. The
host does not invent a details/query-wide readiness validator. Same-child reentry,
source/P loss, malformed current capture, no eligible A, raw-A cancellation,
foreign/reused receipts and irreversible/post-cancel errors retain fail-closed/

Raw adopted own-`className` behavior and all raw legacy bodies remain intact.
