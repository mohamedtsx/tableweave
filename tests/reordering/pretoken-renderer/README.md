   notification wrapper. Port capture fields are cleared on retirement; prepared

   one key in actual registered N scope/row/handle slots and the original core stamp

   was added. Core's entire delta is three native-only action-cut calls; original
   timer/rAF debt, tools/details and SKIP policy bodies remain unchanged.
