### Fixed read roles and failure precedence

`OBSERVE` is the library-selected empty-ID source read. It checks the original SRC/
lease and exact genuine D/ND/CD/C/P/source/tool/frame/native/query proofs. UI cleanup
alone cannot fail its source/finally gates. `ACT` additionally checks the original
UI attempt, including placement-proxy reentry **before** the pure port is entered.
No application predicate, allowing boolean, ref.current/latest lookup or public role
option chooses a role. Row capture adds an outer UI cut to its empty-ID source read.

Metadata capture parses the original returned descriptors/values under SRC before
the ACT UI exit check: an original throw or malformed/changed result cannot be masked
by a simultaneous UI change. Original failed calls are not overwritten by a finally
UI interruption. Native/eligibility guards retain their genuine authority/body and
source checks. U1 extent derivation/policy/stamp/page-ID construction and actual native
facts/membership/budget comparisons remain byte-identical source fragments.

UI interruptions are private, single-use, exact-boundary receipts, consumed before
public boundaries. Recovery verifies the original SRC/lease, exact registered source
signature and truthful captured metadata using real current ports. It is validation
of the pinned cut, **not** a new source grant or read-latest fallback. Failure or an
unknown/copied/public/foreign/replayed signal never suppresses source retirement.
The receipt stores weak identity tags and primitive metadata, not actual models/rows.
The adapter also authenticates its own eligibility denial instead of trusting an
arbitrary public `error.code === "reorder.eligibility"` supplied by an app.

Wrapper coherence authenticates both actual models independently. The fingerprint
excludes only the model wrapper and context-container pointer, while retaining exact
registered owner/P/frame/caps/native/query identity and C-state/mode/epoch checks.
Thus copied context objects do not spuriously retire an otherwise live observation;
equal D/C/IDs/epoch strings or a different P2 source owner never establish continuation.
Action joins still require the sole helper-current exact model, not a copied wrapper.
